# Code availability

This package contains the publication-oriented analysis code used
to construct the Sepsis Atlas.

It includes preprocessing and quality control, study-specific
loading, metadata and feature harmonization, primary integration,
compartment-specific annotation, validation, global reconciliation,
and final annotation freezing.

Developer-specific absolute paths and local scheduler wrappers
not required for the scientific workflow were excluded.

Software-environment information is provided in `environment/`.
File integrity is documented in `SHA256SUMS_RELEASE.txt`.
